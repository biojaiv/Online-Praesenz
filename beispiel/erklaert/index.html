Wie wird aus einem Karton ein Arbeitsplatz?

Wenn jemand neu anfängt, steht zuerst ein eingepackter Laptop da. Bis Jana damit arbeiten kann, müssen sieben Dinge passieren. In einer gut geplanten IT laufen viele davon fast von selbst. Tiefgang zeigt dir, wie das aussieht — und du darfst dabei sogar ein Kabel ziehen.

Drei Lesetiefen: dasselbe Kapitel, je nach Interesse

Der Regler „Lesetiefe“ schaltet im Erlebnis zwischen den Ebenen um. Einfach ist der Standard; Fachwissen bleibt einen Klick entfernt. Hier siehst du das Beispiel DHCP.

Einfach

für alle

Der Laptop bittet das Netz um eine Adresse und bekommt eine. Wie eine Hausnummer für die Post.

Erklärt

für Interessierte

Der DHCP-Server vergibt Adresse, Gateway und DNS in vier Schritten: Discover, Offer, Request, Acknowledge. Erst nach der Bestätigung darf der Laptop die Adresse benutzen.

Technik

für Fachleute

DHCPDISCOVER → broadcast
 DHCPOFFER 10.20.0.42
 GW 10.20.0.1 · DNS 10.20.0.10
 DHCPREQUEST → DHCP-01
 DHCPACK ← Lease bestätigt

Glossar in einem Satz

Client
Das Gerät, an dem jemand arbeitet. Hier: Janas Laptop.
Switch
Kabelverteiler: verbindet alle Geräte im Haus miteinander.
Access Point
Sendestation für das WLAN.
Firewall
Pförtner zwischen Netzen: lässt nur Erlaubtes durch.
VLAN
Getrennte „Spuren“ auf derselben Verkabelung.
Uplink
Die Leitung zwischen zwei Netzwerkgeräten, hier zwischen Switch und Firewall.
DHCP
Verteilt automatisch Netzwerkadressen.
DNS
Telefonbuch des Netzes: macht aus Namen Adressen.
Gateway
Die Ausfahrt aus dem eigenen Netz zu anderen Netzen.
PXE
Start über das Netzwerk statt von einem USB-Stick.
Active Directory
Zentrales Verzeichnis für Konten, Gruppen und Rechte.
Hypervisor · VM
Der Hypervisor teilt einen Server in mehrere virtuelle Server (VMs).
UEM (baramundi)
Verwaltung, die Programme und Einstellungen auf Geräte bringt. baramundi ist ein solches Produkt.
Redundanz
Wichtiges gibt es doppelt, damit der Betrieb bei einem Ausfall weiterläuft.
Backup · Restore
Ein Backup ist die Kopie der Daten an einem anderen Ort. Restore holt sie zurück.

Warum das alles automatisieren?

Weniger Fehler

Jeder Laptop bekommt dieselben geprüften Schritte, nicht jedes Mal etwas anderes.

Nachvollziehbar

Die IT sieht, was installiert wurde und ob es geklappt hat.

Mehr Zeit für Menschen

Wer nicht von Hand installiert, kann sich um Probleme kümmern, die wirklich Köpfchen brauchen.

Modell oder Praxis?

IM MODELL (TIEFGANG)

Jana, der Laptop und die 35 Minuten sind ein anschauliches Modell. Die Zeit ist verdichtet, nicht gemessen. Die Kapitel zeigen einen logischen Weg, keinen verbindlichen Bootablauf oder vollständigen Netzplan.

IN DER PRAXIS (ABSCHLUSSPROJEKT)

Landratsamt Enzkreis: baramundi-Pilotumgebung als Grundlage für einen möglichen späteren Ersatz von Matrix42 Empirum. 40 Stunden, vier vollständig erfolgreiche Referenzclients bei fünf geplanten. Ein Pilot, keine vollständige Produktionsmigration.
