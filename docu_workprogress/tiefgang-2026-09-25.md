# Tiefgang — local implementation / lokale Umsetzung

## Experience

The existing `/beispiel/` entry now tells Jana’s first-workday story in seven ordered chapters. The existing middle-pedestal projection and its same-origin message protocol remain the entry and return path. All visitor-facing copy is available in English and German.

- Warm paper, local Barlow Condensed font (SIL OFL), ink SVG hardware and amber highlights.
- ScrollTrigger reads native document scrolling. Chapter links, previous/next buttons and Page Up/Down provide direct navigation. The final half viewport recombines the drawing and reveals the ready screen.
- `state.js` coordinates chapter progress, DHCP DORA, the VM drawer and the uplink state machine (`primary → failing → backup → primary`). The cable switch disconnects a switch-to-firewall uplink, not the laptop’s only access link. Failure convergence pauses when the projection or browser is hidden.
- xterm.js and its FitAddon load on first terminal activation. `help`, `ping`, `ipconfig`, `gpresult`, `whoami`, `clear` and `exit` use the current chapter and network state. They are simulated browser commands, never a server shell. Command history, bounded input, focus containment and nested ESC handling are supported.
- Chapter 4, chapter 6 and the final screen link to the real final qualification project. The pilot’s actual scope and four successful reference clients are distinguished from the illustrative 00:04:12 model timeline.
- Reduced motion has seven ordinary readable chapters with still SVG illustrations. `scripts/example/build_static.mjs` renders both languages into the HTML for the no-JavaScript path; it runs before each production build.
- The drawing uses no GPU canvas, continuous animation loop or remote font request. The existing portfolio renderer pauses behind the opened projection. SVG motion follows scroll input; the failover uses a single pausable timer.

## Verification commands

With the local preview serving the built application:

```sh
npm run build
EXAMPLE_URL=http://127.0.0.1:4173 npm run test:tiefgang
```

With Vite serving development assets:

```sh
npm run build:example-previews
npm run test:example
npm run test:example:preview
```

The focused Tiefgang check covers ten language/viewport combinations, ordered chapters, DHCP replay, failover/reconnection, the VM drawer, chapter-dependent terminal responses, keyboard focus, the final screen, reduced motion and bilingual HTML without JavaScript. Existing projection tests additionally cover the camera transition, embedded wheel/touch input and ESC return.
